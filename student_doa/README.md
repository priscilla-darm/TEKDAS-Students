# EduSight — Student Outcome Intelligence

A Streamlit student-outcome analytics app based on the workflow in the supplied `simulation.zip`, adapted to `student_doa_dataset.csv`.

## Run the dashboard

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

Keep `student_doa_dataset.csv` beside `app.py`, or set the `STUDENT_DOA_DATA` environment variable to the full dataset path.

## Simulation-equivalent companion workflow

The companion scripts mirror the data-preparation → ML → analyst structure of the original simulation, but use student outcomes rather than customer churn.

```bash
python data_prep.py
python ml_model.py
python vai_analyst.py --prompt-only
```

Optional local LLM check (requires Ollama installed and running):

```bash
ollama serve
ollama pull llama3.2
python vai_analyst.py --model llama3.2
```

## Project files

- `app.py` — interactive Streamlit dashboard.
- `student_doa_dataset.csv` — original dataset supplied by the user.
- `data_prep.py` — validates the target and generates a stable record ID, model-ready dataset, stratified train/test split, and quality report.
- `ml_model.py` — trains and evaluates a multiclass Random Forest, exports feature importance, predictions, metrics, and a model pipeline.
- `vai_analyst.py` — optional Ollama-based, evidence-grounded student-support analyst with a prompt-only mode.
- `student_ml_dataset.csv` — full model-ready table (record ID included only for traceability).
- `student_train.csv`, `student_test.csv` — stratified 80/20 split (random seed 42).
- `data_quality_report.json` — schema, class counts, missingness, duplicate count, and split metadata.
- `student_outcome_pipeline.pkl` — trained scikit-learn pipeline bundle generated by `ml_model.py`.
- `feature_importance.csv` — global model feature importances after preprocessing.
- `student_predictions.csv` — held-out predictions and probabilities for all three outcomes.
- `model_metrics.json` — held-out accuracy, macro/weighted F1, dropout precision/recall, confusion matrix, and per-class report.
- `requirements.txt` — Python dependencies.

## Dataset and modeling notes

- Target: `Target`, with `Dropout`, `Enrolled`, and `Graduate`.
- Categorical numeric codes are treated as categories during preprocessing.
- Model metrics are measured on a held-out stratified test split; they are not a guarantee of future performance.
- The data includes second-semester academic results. A model using these columns should not be described as an early-enrollment risk model.
- Feature importance shows model association, not causation.
- Predictions should support voluntary, human-reviewed student support, never automated punitive or high-impact decisions.
- `vai_analyst.py --prompt-only` does not need an LLM connection. To call Ollama, install the Python package and run the local Ollama service/model.

The data-preparation and model-training scripts regenerate their output CSV/JSON/model files when run.
